# Mahender — Official Portfolio

Angular standalone portfolio for Mahender Chakali.

## Positioning
Senior AI-Native Software Engineer | Angular | TypeScript | Java | Microservices | LLMs | AI Agents

## Included
- Professional hero and executive summary
- About / career overview
- Experience timeline
- Education
- Technical skills
- Featured enterprise projects
- AI-native engineering capabilities
- Services
- Contact / social links
- Responsive desktop + mobile design
- SEO metadata and Open Graph basics
- No backend required for the initial static portfolio

## Run
1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:4200`.

## Customize
Edit `src/app/app.component.ts` for portfolio content and links.
Replace `src/assets/profile.jpg` with a professional photo when available.

## Build
`npm run build`

The production output is generated under `dist/`.
